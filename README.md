# AntiPorn Guard

برنامج سطح مكتب لويندوز للرقابة الأبوية وحجب المواقع الإباحية — شبيه بفكرة TuEagles Anti-Porn، مكتوب بـ Python.

## المميزات
- **حجب المواقع** عن طريق ملف `hosts` في النظام (قائمة سوداء + قائمة بيضاء + كلمات ممنوعة).
- **حماية بكلمة مرور**: الدخول، تغيير الإعدادات، وإغلاق البرنامج كلها محمية.
- **سجل الأحداث**: تسجيل الحجب واللقطات.
- **تحديد وقت الاستخدام**: تنبيه خارج الساعات المسموحة.
- **لقطات شاشة دورية** (تحتاج مكتبة Pillow).

## التشغيل (للتجربة)
```bash
pip install -r requirements.txt
python app.py
```
> على ويندوز شغّل الـ Command Prompt **كمسؤول (Run as administrator)** قبل ما تنفذ `python app.py`، وإلا الحجب في ملف hosts مش هيشتغل.

## تحميل الـ .exe الجاهز (الأسهل)
المشروع فيه GitHub Actions بيبني الـ `.exe` أوتوماتيك على ويندوز:
1. ادخل تبويب **Actions** في الريبو.
2. افتح آخر تشغيل ناجح لـ "Build Windows EXE".
3. نزّل الملف من قسم **Artifacts** باسم `AntiPornGuard-exe`.

أو اعمل Release: نفّذ `git tag v1.0.0 && git push --tags` وهيتعمل Release تلقائي بالـ exe مرفق.

## عمل ملف تنفيذي (.exe) يدويًا على ويندوز
```bash
pip install pyinstaller pillow
pyinstaller --noconsole --onefile --name "AntiPornGuard" app.py
```
الملف هيطلع في مجلد `dist\AntiPornGuard.exe`.

### تشغيله كمسؤول دائمًا
اعمل كليك يمين على الـ exe ← Properties ← Compatibility ← فعّل "Run this program as an administrator".

## أول تشغيل
أول مرة هيطلب منك تعمل كلمة مرور. احفظها كويس — من غيرها مش هتقدر تدخل على الإعدادات أو توقف الحجب.

## أين تُخزَّن البيانات
`%LOCALAPPDATA%\AntiPornGuard\` — قاعدة البيانات (`guard.db`)، واللقطات في مجلد `screenshots`.

## ملاحظات مهمة وحدود البرنامج
- البرنامج أداة رقابة/حجب ذاتي، **مش حماية ضد مستخدم خبير**. أي حد عنده صلاحيات admin يقدر يعدّل ملف hosts يدويًا أو يقفل البرنامج من Task Manager.
- الحجب عبر hosts بيشتغل على مستوى الدومين، مش بيفلتر محتوى داخل المواقع المسموحة.
- عشان تقويه أكتر: استخدم DNS عائلي (زي CleanBrowsing / OpenDNS Family) على مستوى الراوتر، وفعّل حساب Standard User للطفل من غير صلاحيات admin.

## كيفية التقوية (خطوات اختيارية لاحقًا)
1. تشغيل البرنامج كـ Windows Service عشان يفضل شغال.
2. منع تعديل hosts يدويًا بصلاحيات نظام.
3. دمج قائمة حجب كبيرة محدَّثة أونلاين.
